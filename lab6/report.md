4. Контрольные вопросы

Что такое командная строка?
Командная строка — это интерфейс взаимодействия пользователя с операционной системой путем ввода текстовых команд.
При помощи какой команды можно определить абсолютный путь текущего каталога?
Команда pwd (print working directory). Пример: pwd → /home/yusufabdulnasir
При помощи какой команды и каких опций можно определить только тип файлов и их имена в текущем каталоге?
Команда ls -F добавляет символы к именам файлов: / для каталогов, * для исполняемых файлов, @ для ссылок.
Каким образом отобразить информацию о скрытых файлах?
Команда ls -a показывает все файлы, включая скрытые (начинающиеся с точки).
При помощи каких команд можно удалить файл и каталог?

Файл: rm имя_файла
Каталог: rm -r имя_каталога или rmdir имя_каталога (для пустых каталогов)
Каким образом можно вывести информацию о последних выполненных пользователем командах?
Команда history выводит список последних выполненных команд с номерами.
Как воспользоваться историей команд для их модифицированного выполнения?
С помощью конструкции !номер:s/что_меняем/на_что_меняем.
Пример: !13:s/ls/ll — выполняет команду под номером 13, заменяя ls на ll.
Приведите примеры запуска нескольких команд в одной строке.
cd /tmp; ls -la — сначала переход в /tmp, затем просмотр содержимого.
mkdir test && cd test — создание каталога и переход в него (только если первая команда успешна).
Дайте определение и приведите примера символов экранирования.
Экранирование — способ использования специальных символов как обычных.
Пример: echo "Цена \$100" — выведет "Цена $100", где \$ экранирует символ $.
Охарактеризуйте вывод информации на экран после выполнения команды ls с опцией l.
Вывод содержит: тип файла, права доступа, количество ссылок, владельца, группу, размер, дату последнего изменения, имя файла.
Что такое относительный путь к файлу?
Относительный путь не начинается с корня / и задается относительно текущего каталога.
Пример абсолютного пути: /home/yusufabdulnasir/Documents
Пример относительного пути: Documents (из домашнего каталога)
Как получить информацию об интересующей вас команде?
С помощью команды man. Пример: man ls
Какая клавиша или комбинация клавиш служит для автоматического дополнения вводимых команд?
Клавиша Tab (табуляция) автоматически дополняет имена команд, файлов и каталогов.
